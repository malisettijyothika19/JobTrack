# JobTrack – Job Application Tracker

JobTrack is a Flask-based web application that helps users track their job applications in one place.

## Features

- Add new job applications
- View all job applications
- Edit application details
- Delete job applications
- Track application status
- Store application dates
- SQLite database
- Responsive and clean UI

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS

## Application Status

- Applied
- Interview
- Selected
- Rejected
